## 📊 Project Overview

**AstroAI** is a comprehensive astrology platform combining:
- 🔮 Vedic (Jyotish) and Western astrology systems
- 🤖 AI-powered interpretations using GPT-4
- 👁️ Computer vision (face reading, palmistry)
- 🔢 Numerology calculations
- 📅 Hindu Panchang calendar
- 💳 Payment processing (Stripe, Razorpay)
- 👨‍⚕️ Astrologer consultation booking
- 📊 Interactive dashboards

## 🏗️ Technology Stack

- **Frontend**: Next.js 16.0.8, React 19.2.1, TypeScript, Tailwind CSS v4
- **Backend**: Python 3.11, FastAPI, SQLAlchemy, Alembic
- **Database**: PostgreSQL 15 with pgvector extension
- **AI/ML**: OpenAI GPT-4, MediaPipe, OpenCV
- **Infrastructure**: Docker Compose, Redis, RabbitMQ
- **Astrology**: Swiss Ephemeris (pyswisseph)
